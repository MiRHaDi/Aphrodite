# افرودیت (Aphrodite)

**درگاه لبه‌ای پایدار و پنل مدیریت دو‌زبانه**

[English](README.md) · [راهنمای استقرار](docs/DEPLOYMENT.fa.md) · [معماری](docs/ARCHITECTURE.md) · [امنیت](SECURITY.md)

افرودیت یک لایهٔ سبک، قابل‌بررسی و ماژولار روی Cloudflare Workers است. لینک اشتراک کاربران را ثابت نگه می‌دارد، بین مبداهای مجاز جایگزین می‌شود، مسیرهای WebSocket را مدیریت می‌کند، تنظیم مسیریابی هوشمند را می‌فرستد و یک پنل زیبا برای مدیریت کاربران و مشاهدهٔ وضعیت گره‌ها ارائه می‌دهد.

## قابلیت‌ها

- ساخت کاربر با سقف حجم و زمان یا حالت نامحدود
- لینک ثابت `/feed/نام‌کاربر` مستقل از آدرس پنل اصلی
- حالت هوشمند داخل و خارج ایران: سایت‌های ایرانی برای کاربر خارج از ایران از خروجی ایران و برای کاربر داخل ایران مستقیم باز می‌شوند
- بدون نیاز اجباری به فایل‌های GeoIP و GeoSite و در نتیجه بدون خطای `section ip in geosite`
- پشتیبانی مدیریتی از پروفایل‌های VLESS، VMess، Trojan و Shadowsocks و انتقال‌های WS، gRPC، HTTPUpgrade و XHTTP در صورت پشتیبانی سرور
- کش لبه‌ای، چند مبدا، چند هدف تونل و Relay اختیاری مستقل برای افزونگی
- ثبت رویدادهای مدیریتی در D1 و کاهش خواندن دیتابیس به یک جستجوی ایندکس‌شده در هر cache miss
- توکن مدیریت، مقایسهٔ امن، اعتبارسنجی ورودی، Query پارامتری و هدرهای امنیتی

## شروع سریع

```bash
git clone https://github.com/MiRHaDi/Aphrodite.git
cd Aphrodite
npm ci
cp wrangler.toml.example wrangler.toml
npx wrangler d1 create aphrodite-db
# database_id را در wrangler.toml قرار دهید
npm run db:migrate:remote
npx wrangler secret put ADMIN_TOKEN
npx wrangler secret put CONTROL_PLANE_TOKEN
npm run deploy
```

اگر توکن ثابت ندارید، به‌جای آن secretهای `CONTROL_PLANE_USERNAME` و `CONTROL_PLANE_PASSWORD` را ثبت کنید. رمزها، لینک واقعی کاربران و نشانی خصوصی سرورها را وارد Git نکنید.

پنل در `/panel`، سلامت سرویس در `/healthz` و اشتراک هر کاربر در `/feed/<username>` است.

## نکتهٔ فنی پروتکل‌ها

Worker برای HTTP و WebSocket مناسب است و UDP یا TCP خام را مانند یک VPS اجرا نمی‌کند. بنابراین WireGuard، OpenVPN و TCP خام باید روی سرور یا سرویس سازگار اجرا شوند؛ افرودیت می‌تواند پروفایلشان را مدیریت و منتشر کند، اما محدودیت شبکهٔ Worker را پنهان نمی‌کند.

## استفادهٔ مسئولانه

این پروژه برای مدیریت شبکه و سرویس‌هایی است که مالکشان هستید یا مجوز ادارهٔ آن‌ها را دارید. قوانین محل استفاده، شرایط ارائه‌دهنده، رسیدگی به سوءاستفاده و مصرف منابع بر عهدهٔ مدیر سرویس است. در پروژه روش مخفی‌سازی سورس برای دورزدن تشخیص ارائه‌دهنده، برداشت رمز یا جمع‌آوری پراکسی عمومی وجود ندارد.

# پروفایل سازگاری اتصال

برای کلاینت‌هایی که به تنظیم صریح WebSocket روی TLS نیاز دارند، همان لینک اشتراک با `?profile=compat` قابل استفاده است. لینک اصلی اشتراک حفظ شده است.

پروفایل سازگاری، برای لینک‌های VLESS و Trojan با WebSocket و TLS، از ALPN برابر `http/1.1` و تأیید گواهی استفاده می‌کند. اثر انگشت خالی یا `unsafe` با `chrome` جایگزین می‌شود. پروتکل‌های دیگر و تنظیمات JSON و YAML بدون بازنویسی عبور می‌کنند.

اگر مدیر متغیر اختیاری `EDGE_ADDRESSES` را با IPهای تأییدشده تنظیم کند، حداکثر هشت آدرس جایگزین به این پروفایل اضافه می‌شود. SNI، Host و مسیر هر اتصال حفظ می‌شوند و مبدأ پشتیبان مستقل تغییر نمی‌کند. این آدرس‌ها خروجی کشور جدید ایجاد نمی‌کنند؛ فقط روش دسترسی به همان لبه‌اند. هیچ IP آزمایش‌نشده‌ای به‌صورت پیش‌فرض فعال نشده است.

این قابلیت با بررسی سورس Worker متعلق به همین حساب و با پیاده‌سازی مستقل نوشته شد. افزودن پروفایل به‌تنهایی تضمین افزایش سرعت یا کارکرد روی تمام ISPها نیست و باید از اینترنت کاربران آزمایش شود.

# استقرار عملیاتی

۱. یک کنترل‌پلین سازگار و مجاز آماده کنید و نام inboundها را با `src/config.ts` یکسان کنید یا فهرست را مطابق سامانهٔ خود تغییر دهید.

۲. یک D1 بسازید، `wrangler.toml.example` را با نام `wrangler.toml` کپی و شناسهٔ دیتابیس را وارد کنید.

۳. با `npm run db:migrate:remote` جداول را بسازید.

۴. یک `ADMIN_TOKEN` تصادفی حداقل ۳۲ بایتی بسازید. برای پنل اصلی نیز توکن ثابت یا نام کاربری و رمز را فقط با `wrangler secret put` ثبت کنید.

۵. مبدا اصلی، مبداهای پشتیبان و مسیرهای تونل را در فایل تنظیمات قرار دهید؛ سپس `npm run check`، `npm test` و `npm run deploy` را اجرا کنید.

۶. دامنهٔ اختصاصی Worker را متصل و سلامت، ورود پنل، ساخت کاربر آزمایشی و تک‌تک انتقال‌ها را بررسی کنید.

هنگام مهاجرت، دامنه‌های قبلی اشتراک را فعال نگه دارید تا کاربران نیاز به دریافت لینک جدید نداشته باشند. برای Relay اختیاری پوشهٔ `relay/` را جداگانه Deploy کنید و health check را روی `/healthz` بگذارید.

# منابع Cloudflare Pages

پنل افرودیت شش استقرار متعلق به همین حساب را در بخش «منابع Cloudflare Pages» بررسی می‌کند:

- `p1.pages.dev` تا `p6.pages.dev`
- بررسی از سمت Worker و با مهلت ۴٫۵ ثانیه انجام می‌شود.
- کد وضعیت، زمان پاسخ و عنوان صفحه در پنل نمایش داده می‌شود.
- مقصد خراب یا غیرفعال با وضعیت قرمز مشخص می‌شود.
- سورس عمومی صفحهٔ اصلی استقرارهای سالم با دکمهٔ «دریافت سورس» قابل دانلود است.
- صفحهٔ ایستا هرگز به‌اشتباه به‌عنوان تونل WebSocket یا خروجی VPN استفاده نمی‌شود.

در بازیابی عمومی اولیه، فایل‌های ایستای قابل دریافت از `p3` و `p5` آرشیو شدند. `p2` پاسخ 522 و `p4` پاسخ 404 داشتند؛ `p1` و `p6` در مهلت بررسی عمومی پاسخ ندادند. کد Functions سمت سرور از خروجی عمومی Pages قابل استخراج نیست و برای بازیابی آن به دسترسی Deployments/منبع Git همان پروژه نیاز است.

متغیر اختیاری `PAGES_SOURCES_JSON` فقط همین شش میزبان را می‌پذیرد. این محدودیت مانع تبدیل API پایش به SSRF می‌شود.

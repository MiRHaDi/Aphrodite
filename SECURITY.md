# Security policy

Please report vulnerabilities privately through GitHub Security Advisories. Do not include live credentials, subscription links, user databases, or server addresses in public issues.

Supported releases receive security fixes on the latest major version. Rotate `ADMIN_TOKEN` and control-plane credentials after any suspected disclosure. Keep `wrangler.toml`, `.dev.vars`, exports, and database snapshots out of Git.

Aphrodite is intended for networks and accounts you own or are authorized to administer. Operators are responsible for provider terms, local law, abuse handling, and acceptable-use controls.
